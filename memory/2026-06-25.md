### 发布流程
1. 修改源码 → 
2. `mvn package -DskipTests -q` → 
3. `kill <旧pid>` → 
4. `nohup java -jar target/mes-query-api-1.0.0.jar > app.log 2>&1 &` → 
5. 验证 curl
